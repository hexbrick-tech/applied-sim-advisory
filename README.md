# Applied SIM for Advisory

> Applying Semantic Isolation Method (SIM) to advisory workflows.

## Overview

Applied SIM for Advisory defines a domain model for applying the Semantic Isolation Method (SIM) to advisory workflows.

It evaluates existing technical investigation results or AI-generated research outputs from an independent perspective, identifies gaps, and provides structured opinions while preserving the semantic boundaries defined by SIM.

This repository builds on:

- [Semantic Isolation Method (SIM)](https://github.com/hexbrick-tech/sim)
- [Applied SIM Standard Guidelines (ASG)](https://github.com/hexbrick-tech/applied-sim-standard-guidelines)

## Scope

This repository focuses on the evaluation and advisory layer around technical investigation results.

It covers:

- evaluation of technical investigation results
- evaluation of AI-generated research outputs
- gap identification
- structured opinions
- review cycles and reporting projections

It does **not** define how the underlying investigation itself is performed.
